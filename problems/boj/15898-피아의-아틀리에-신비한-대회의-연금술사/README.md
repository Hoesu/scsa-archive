# 피아의 아틀리에 ~신비한 대회의 연금술사~

> 원문: [boj 15898](https://bowlog.tistory.com/41) · 레벨 `G1` · 공통 난이도 `4`

## 문제 요약

<!-- 원문을 복사하지 말고 "무엇을 입력받아 무엇을 구하는지" 2~4줄로 직접 요약하세요. (저작권 보호) -->
4×4 재료 n개(3 ≤ n ≤ 10)가 주어지며, 각 칸에는 효능(-9~9)과 원소(R/B/G/Y/W)가 있다.
서로 다른 재료 3개를 골라 순서·회전·위치를 정해 5×5 가마에 차례로 넣는다. 넣을 때마다 겹친 칸의 품질에는 효능이 더해지고(0~9로 보정), 원소가 W가 아니면 칸의 색이 그 원소로 바뀐다.
최종 가마에서 색별 품질 합으로 계산한 `7R + 5B + 3G + 2Y`의 최댓값을 구하는 문제.

## 이 문제를 추천하는 이유

1) 문제 읽자마자 창 닫고 싶음 => 진득한 기출의 향기
2) 테케 제공되고, testcase.ac에 등록되어 있음
3) 실수 안하고 빡구현 + 시간복잡도 나름 신경쓰며 완전탐색 연습
4) 백트래킹도 가미되어 있긴한데, 그게 메인 디시는 아님

## 핵심 포인트 / 함정

<!-- 제한 조건, 엣지 케이스, 자주 틀리는 부분 (풀이를 직접 노출하지 않는 선에서) -->
- 재료를 넣는 **순서**가 결과에 영향을 준다 (조합이 아니라 순열).
- 품질은 재료를 넣을 **때마다** 0~9로 보정된다. 마지막에 한 번만 보정하면 틀린다.
- 원소가 `W`인 칸은 색을 바꾸지 않는다 (효능은 그대로 더해짐).
- 가마 밖으로 나갈 수 없으므로 위치는 (0,0)~(1,1) 4가지, 회전은 4가지.
- 흰색 칸의 품질은 점수에 포함되지 않는다.
