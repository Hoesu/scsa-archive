# 행렬 테두리 회전하기

> 원문: [programmers 77485](https://school.programmers.co.kr/learn/courses/30/lessons/77485?language=java&gad_source=1&gad_campaignid=22356298761&gbraid=0AAAAAC_c4nDtlcqqydkNIAku5Cjs5iSfH&gclid=CjwKCAjwgJHXBhBGEiwAHohJq2sxrj8JXKV8VnrT0chiKTrCEGzkiuBYkEN9rfxkfln8Dn8f349zQhoC2F8QAvD_BwE) · 레벨 `Lv.2` · 공통 난이도 `3`

## 문제 요약

배열 크기와 회전할 영역 좌표를 입력 받아서 테두리를 시계 방향으로 한 칸 회전시키고, 회전할 때마다 이동한 숫자 중 최솟값을 구한다.

## 이 문제를 추천하는 이유

복잡한 알고리즘보다는 인덱스 처리와 값 덮어쓰기 정확하게 하는지 확인할 수 있는 간단한 리프레시용 문제

## 핵심 포인트 / 함정

* 일반적인 회전과 다르게 지정된 영역의 테두리만 회전한다.
* 새로운 값으로 덮어쓸 때 주의해야 함.
